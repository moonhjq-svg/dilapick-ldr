# DilaPick-LDR: minimal reproducibility release

This repository provides the four recovery configurations used in Table I of the
2026-10-08 manuscript: DilaPick (internal reference), DilaPick-LDR (`LDR`), Linear,
and Narrow. It includes all 12 frozen checkpoints, validation thresholds, the
100,000-record split index, and 12 x 10,000 frozen test predictions.

This is a minimal inference and frozen-prediction rescoring release. Full training
from raw data has **not** been rerun in a clean environment. Historical training
sources are under `reference_training/`; they are provenance records, not supported
standalone training commands. This directory is separate from the LaTeX source package.

## Install

Test target: Python 3.10, CPU PyTorch 2.5.1, NumPy 1.26.4. From the repository root:

```sh
python -m venv .venv
```

Activate with `.venv\Scripts\Activate.ps1` in Windows PowerShell, or
`source .venv/bin/activate` on Linux/macOS. Then:

```sh
python -m pip install --upgrade pip
python -m pip install -r requirements.txt --extra-index-url https://download.pytorch.org/whl/cpu
python verify_files.py
python infer.py --model LDR --seed 42
python reproduce_table.py
```

The demo uses deterministic synthetic input and an actual trained checkpoint.
It verifies execution, shapes and finite outputs; it is not an accuracy test.
For a raw waveform saved as a NumPy array:

```sh
python infer.py --model LDR --seed 42 --input waveform.npy --output outputs/prediction.npz
```

Input: 60 seconds, 100 Hz, channels Z/N/E, `[3,6000]`, `[6000,3]`, or
`[B,3,6000]`. Each channel is demeaned and divided by its population standard
deviation (floor `1e-6`). Output NPZ contains D/P/S probability sequences,
maximum probabilities, peak samples, and frozen-threshold decisions. Detection's
peak sample is merely the maximum-probability location, not an onset estimate.
No continuous-stream preprocessing, resampling or instrument correction is supplied.
Use `--model DilaPick`, `--model Linear`, or `--model Narrow`, and seeds 41, 42, 43.
Model definitions are unchanged frozen source snapshots. Checkpoints are tensor-only
exports, verified elementwise equal to the original trained states; optimizer and
training metadata are omitted. Weight hashes and original-checkpoint hashes and origin
identities are in `evidence/provenance.json`; redistribution files are covered by
`SHA256SUMS.json`.

## Reproduce results

`python reproduce_table.py` needs only Python's standard library and no waveform
download. It verifies input hashes, ordered test identities, labels and thresholds,
recomputes D/P/S F1 and P/S mean F1, and requires all 32 six-decimal mean/sample-SD
cells to match the bundled manuscript Table I. It writes:

- `outputs/table_recovery_controls.csv`
- `outputs/per_seed_metrics.csv`
- `outputs/table_verification.json`

Each window supplies at most one prediction per phase. The phase matching tolerance
is 50 samples. A predicted phase outside tolerance counts as both FP and FN on an
event. Reference arrivals use `int(round(original metadata arrival sample))`, matching
the September 24 rescoring used by the current manuscript. No thresholds or weights
are selected using test data. Statistics use equally weighted seeds and sample SD.

| Manuscript result | Included evidence and support |
| --- | --- |
| Table I, four recovery models | Fully rescored from frozen predictions |
| Tight-tolerance and common-TP analyses | Historical result CSVs in `evidence/expected/`; not regenerated by this entry point |
| Depth / INSTANCE transfer tables | Outside this minimal release; original evidence package remains the source |
| Jetson / TensorRT and external references | Not reproduced here; requires original hardware and protocol-specific pipelines |

## Data and experiment settings

See [DATA.md](DATA.md) for dataset acquisition, frozen splits, and label conventions.
`configs/training_protocol_original.json` preserves the historical control-training
lock, including batch size 32, 20 epochs, AdamW and cosine schedule, seed choices,
validation selection and threshold grid. Historical absolute paths inside provenance
and training records identify originals; inference and scoring use relative paths.
The four models were trained independently, with shared encoder/context definitions.
Linear retains the shallow detail branch and replaces only deep context recovery;
Narrow has width 3 and is a complete alternative configuration.

The repository is prepared locally; no public URL is asserted. MIT applies to
author-owned code under [LICENSE](LICENSE); dataset rights and external dependencies
are described in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

## Validation scope

See `validation/validation_report.json` for actual clean-environment results.
